====================================================
PlugnPay Remote API Module
Payment module for Miva Merchant v4.x (Windows NT)
Package: commerce library DLL (legacy)
====================================================

***** IMPORTANT NOTES *****
This module is provided "AS IS". Limited technical support assistance
will be given to help diagnose/address problems with this module.

- Declared in plugnpay.mv: Miva Merchant v4.x
- Module_API_Version: 4.14
- Module_Version: 4.2400
- Includes pnpmiva.dll for Miva Mia / Empresa commerce registration
- Posts to https://pay1.plugnpay.com/payment/pnpremote.cgi
- Historically named miva_nt_pre4.0.zip / PnPMiva_NT.zip (identical)
- Prefer miva_4.x_nt_api_module.zip (2008-03-13) when the DLL is not required
***************************

To Install:

1. Download miva_4.x_nt_commerce_lib_api_module.zip from this folder
   (or use src/nt_commerce_lib/ in this repository).

2. Register the commerce library (Miva Mia):
     a. Copy pnpmiva.dll onto the server
     b. Right-click the Miva Mia tray icon → Properties → Commerce
     c. Add → browse to pnpmiva.dll
     d. Method name: PlugNPay  (case-sensitive)

   Or register under Miva Empresa (IIS):
     a. Open Internet Service Manager / IIS admin for the site
     b. Properties → Miva Engine → Commerce Libraries → Add
     c. Method: PlugNPay ; browse to pnpmiva.dll

3. In Miva admin:
     - Modules → Add Module → upload plugnpay.mvc
       (or plugnpay.mv for Merchant below 4.14)
     - Stores → Payment Configuration → enable
       "Plug & Pay Technologies Inc. v1.0" → Update

4. Test an authorization.

Common problems (from original readmemivant.txt):

- Upgrade WinInet / IE if HTTPS posts fail (historical IE 5.5 note).
- "method PlugNPay does not exist" — DLL not registered, or method
  name is not exactly PlugNPay.
