====================================================
PlugnPay Remote API Module
Payment module for Miva Merchant v4.x (Windows NT)
Package: 2008-03-13 (preferred)
====================================================

***** IMPORTANT NOTES *****
This module is provided "AS IS". Limited technical support assistance
will be given to help diagnose/address problems with this module.

- Declared in plugnpay.mv: Miva Merchant v4.x
- Module_API_Version: 4.14
- Module_Version: 4.2400
- Posts to https://pay1.plugnpay.com/payment/pnpremote.cgi
- Card data is collected on your Miva storefront (PCI scope).
- Merchant below 4.14: upload plugnpay.mv
- Merchant 4.14 and above: upload compiled plugnpay.mvc
***************************

To Install:

1. Download miva_4.x_nt_api_module.zip from this folder
   (or use src/nt_20080313/ in this repository).

2. In Miva admin:
     - Click the triangle next to Modules
     - Click Add Module
     - Upload File → choose plugnpay.mvc (or plugnpay.mv if required)
     - Click Add

3. Enable at the store:
     - Stores → your store → Payment Configuration
     - Check "Plug & Pay Technologies Inc. v1.0" → Update
     - Open the PlugNPay configuration tab and set account options
       (including Online vs Offline / authorize-only charge method)

4. Test an authorization. Capture / void / refund for offline
   (auth-only) transactions are done in PlugnPay Merchant Admin.

See also:
  src/nt_20080313/PlugNPay_ReleaseDoc.txt
  src/nt_20080313/PlugNPay_ReleaseDoc.doc

If your Mia/Empresa install still requires a Windows commerce DLL,
use miva_4.x_nt_commerce_lib_api_module.zip and INSTALL_COMMERCE_LIB.txt
instead (or in addition for the library registration step).
