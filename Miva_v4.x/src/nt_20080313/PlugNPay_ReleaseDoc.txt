    Introduction

This document describes the configuration and use of the module itself, and
assumes the reader has a familiarity with the use of the Miva Merchant
administration and runtime interfaces.

In versions of Miva Merchant below 4.14 the non-compiled plugnpay.mv file
should be used, in versions of Miva Merchant 4.14 and above the compiled
plugnpay.mvc file should be used.

PlugNPay  Payment  Module  is   the   recommended   module   of   submitting
transactions to the payment gateway. This module allows a merchant’s  server
to securely connect directly to the payment gateway  to  submit  transaction
data. The merchant retains full control of the payment data  collection  and
the user experience. This module requires merchants to be able  to  initiate
and manage different payment methods.

How does PlugNPay Payment Module Works: -

When using plugnpay, transactions flow in the following way:
   1) The Customers browser connects securely to the Merchants server to
      transmit payment information.
   2) The Merchants server initiates a secure connection to the payment
      gateway and then initiates HTTPS post of the transaction data to the
      gateway server.
   3) The payment gateway receives and processes the transaction data.
   4) The payment gateway then generates and submits the transaction
      response to the Merchants server.
   5) The merchant server receives and processes the response.
   6) Finally, the merchant’s server communicates the success or failure of
      the authorization to the customer browser.

    Module Setup



Use the following procedure to add  plugnpay.mvc  payment  modules  to  your
Miva Merchant domain.
Miva Merchant 4.14 and above: Miva Merchant is compiled.  Any  added  module
must  also  be  compiled.  The  .mvc  identifies  compiled   Miva   Merchant
applications and modules.

1) Click the triangle next to Modules.
2) Click Add Module.

[pic]

 3 If you know the module name, enter it and go to step 5.
 4 If you do not know the module name, click the Upload File button.

[pic]

   The Upload File screen is displayed.
   a. Use the Browse... button to find the module on your system.
   b. You are uploading a new module that is not in your Miva Merchant
domain.
     Therefore, you do not need to click the Overwrite check box.
   c. Click the Upload button to return to the Add Module form.


[pic]


 5 In the Add Module screen, click the Add button.
 6 To undo your steps, click the Reset button to delete the module from  the
   Domain.

[pic]
 7 After you click the Add button, the module (A New Payment Module  in  the
   sample below) is added to the module list as the last item.
 8 The module is enabled at the store level by checking the box next to Plug
   & Pay Technologies Inc. v1.0 and passing the update button.

[pic]

9) Once the module has been enabled a new tab will appear called “Plug &
   Pay Technologies Inc. v1.0”.

[pic]




 1  This new tab is where you will find all the configuration options for
   the module.
